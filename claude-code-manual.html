Slash Commands

Digite esses comandos diretamente no prompt do Claude Code. Estão disponíveis durante qualquer conversa interativa.

Comando Descrição
/help

Exibe a lista de comandos disponíveis e atalhos.
/clear

Limpa o histórico de conversa e inicia uma nova sessão.

Útil para reduzir o uso de tokens quando o contexto fica grande.
/compact

Comprime o histórico mantendo um resumo compacto do contexto.

Preserva a memória da conversa gastando menos tokens.
/config

Abre o menu interativo de configurações (modelo, tema, permissões, etc.).
/cost

Mostra o custo e o número de tokens usados na sessão atual.
/doctor

Diagnostica problemas de configuração, MCP e ambiente.
/exit

Encerra o Claude Code (também funciona com Ctrl+D).
/fast

Alterna o modo rápido (usa Claude Opus com saída acelerada).

Disponível apenas para planos com acesso ao Opus.
/init

Gera um arquivo CLAUDE.md na raiz do projeto com documentação do código base.
/login

Autentica com a conta Anthropic ou troca de conta.
/logout

Desconecta a conta atual do Anthropic.
/memory

Exibe e edita os arquivos de memória CLAUDE.md (projeto, usuário e global).
/model

Troca o modelo de IA em uso (ex: Opus 4.8, Sonnet 5, Haiku 4.5).
/permissions

Gerencia quais ferramentas têm permissão automática (allowlist).
/pr_comments

Busca e exibe comentários de pull requests do GitHub no contexto.
/release-notes

Exibe as notas de lançamento da versão atual do Claude Code.
/resume

Retoma uma conversa anterior (lista sessões salvas).
/review

Realiza code review do diff atual (mudanças staged/unstaged).
/status

Exibe informações da sessão: modelo, custo, tokens e configurações ativas.
/terminal-setup

Instala atalhos e integrações no shell (bash/zsh/fish).
/vim

Ativa o modo de entrada VIM para editar o prompt com keybindings do Vim.
💡
Dica: Você pode instalar skills (plugins de slash commands) via MCP servers. Skills aparecem automaticamente no menu /help após instalação.

Flags da CLI

Passadas ao invocar claude no terminal. Combinam-se com o modo interativo ou não-interativo (--print). 

# Uso geral
claude [flags] [prompt]

# Exemplos
claude "Explique este repositório"
claude --model claude-sonnet-5 --print "Resuma o README"
claude --dangerously-skip-permissions --print "Aplique os testes"
--model <id>

Define o modelo a usar (ex: claude-opus-4-8).
--print / -p

Modo não-interativo: envia o prompt e imprime a resposta no stdout.

Ideal para scripting e pipelines CI/CD.
--output-format

Formato de saída: text (padrão), json ou stream-json.
--max-turns <n>

Limita o número de turnos do agente em modo não-interativo.
--system-prompt

Fornece um prompt de sistema personalizado para a sessão.
--append-system-prompt

Adiciona texto ao prompt de sistema padrão sem substituí-lo.
--allowedTools

Lista de ferramentas permitidas separadas por vírgula (ex: Read,Edit,Bash).
--disallowedTools

Lista de ferramentas bloqueadas separadas por vírgula.
--permission-mode

Define o nível de permissão: default, acceptEdits, bypassPermissions.
--dangerously-skip-permissions

Pula todas as confirmações de permissão (use com cautela em ambientes isolados).
--add-dir <path>

Adiciona diretórios extras ao contexto de trabalho do agente.
--resume <session-id>

Retoma uma sessão específica pelo ID.
--continue

Continua a sessão mais recente automaticamente.
--verbose

Exibe logs detalhados de execução (chamadas de API, tools, etc.).
--debug

Modo debug completo com rastreamento de chamadas internas.
--version

Exibe a versão instalada do Claude Code.
✅
Uso em pipelines: combine --print + --output-format json para integrar o Claude Code em scripts bash, GitHub Actions e outros sistemas de CI/CD.

Atalhos de Teclado

Atalhos disponíveis durante a sessão interativa no terminal.

Atalho Ação
Enter

Envia o prompt atual.
Shift + Enter

Adiciona uma nova linha (prompt multi-linha).
Ctrl + C

Interrompe a resposta em andamento.

Pressione duas vezes para sair do Claude Code.
Ctrl + D

Encerra a sessão (equivalente a /exit).
↑ / ↓

Navega pelo histórico de prompts da sessão.
Ctrl + R

Busca reversa no histórico de prompts.
Ctrl + L

Limpa a tela do terminal (mantém o contexto da conversa).
Esc

Cancela o prompt atual e retorna ao input vazio.
Tab

Auto-completa slash commands e nomes de arquivos.
Ctrl + Z

Suspende o processo (envie fg no shell para retomar).
🎹
Customização: os atalhos podem ser redefinidos em ~/.claude/keybindings.json. Use o comando /keybindings ou edite o arquivo manualmente para criar chord bindings.

Modos de Permissão

O Claude Code solicita confirmação antes de executar ações potencialmente destrutivas. Os modos abaixo controlam esse comportamento.

Default

  • Leitura de arquivos: livre
  • Edição de arquivos: confirmação
  • Comandos Bash: confirmação
  • Ações de rede: confirmação
  • Git/GitHub: confirmação

acceptEdits

  • Leitura de arquivos: livre
  • Edição de arquivos: automático
  • Comandos Bash: confirmação
  • Ações de rede: confirmação
  • Git/GitHub: confirmação

bypassPermissions

  • Tudo automático
  • Recomendado apenas em containers
  • Usado em CI/CD
  • Sem confirmações
  • Máximo de autonomia
# Definir modo via flag
claude --permission-mode acceptEdits

# Ou via settings.json
{
  "permissionMode": "bypassPermissions"
}

# Allowlist de ferramentas no settings.json
{
  "allowedTools": ["Read", "Edit", "Write", "Bash(git *)"]
}
⚠️
Atenção: bypassPermissions desativa todas as confirmações. Use apenas em ambientes isolados (Docker, GitHub Actions, VMs descartáveis). Nunca em máquinas de produção.

Memória — CLAUDE.md

O Claude Code lê arquivos CLAUDE.md para persistir contexto entre sessões. Existem três escopos de memória.

Arquivo Escopo
./CLAUDE.md

Memória do projeto — versionada no repositório, compartilhada com a equipe.

Ideal para convenções de código, arquitetura e contexto do projeto.
~/.claude/CLAUDE.md

Memória do usuário — pessoal, aplicada em todos os projetos.

Ideal para preferências pessoais de estilo e atalhos frequentes.
~/.claude/CLAUDE.local.md

Memória local do projeto — não versionada, específica para sua máquina.

Use para credenciais, paths locais e configurações de ambiente.

 
# Exemplo de CLAUDE.md de projeto

## Arquitetura
- Frontend: Next.js 15 + TypeScript
- Backend: FastAPI + PostgreSQL
- Testes: pytest + Vitest

## Convenções
- Commits em Conventional Commits (feat, fix, chore)
- Sem comentários óbvios no código
- Preferir editar arquivos existentes a criar novos
✅
Geração automática: use /init para que o Claude analise seu repositório e gere um CLAUDE.md inicial com documentação do código base.

Servidores MCP

O Model Context Protocol (MCP) permite conectar o Claude Code a ferramentas externas: bancos de dados, APIs, sistemas de arquivos remotos e muito mais. 

# Adicionar servidor MCP via CLI
claude mcp add <nome> <comando> [args...]

# Exemplos
claude mcp add filesystem -- npx @modelcontextprotocol/server-filesystem /home/user
claude mcp add github -- npx @modelcontextprotocol/server-github
claude mcp add postgres -- npx @modelcontextprotocol/server-postgres postgresql://localhost/mydb

# Listar servidores cadastrados
claude mcp list

# Remover servidor
claude mcp remove <nome>

Configuração manual em ~/.claude/settings.json:

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_..."
      }
    },
    "filesystem": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-filesystem", "/home/user"]
    }
  }
}

Hooks

Hooks são comandos de shell executados automaticamente em resposta a eventos do Claude Code. Configure-os em settings.json.

Evento Quando dispara
PreToolUse

Antes de qualquer chamada de ferramenta (Bash, Edit, Read, etc.).
PostToolUse

Após a conclusão de qualquer chamada de ferramenta.
Notification

Quando o Claude Code envia uma notificação ao usuário.
Stop

Quando o agente termina sua resposta e aguarda input.
SubagentStop

Quando um subagente conclui sua tarefa.
PreCompact

Antes de comprimir o contexto da conversa.
UserPromptSubmit

Imediatamente após o usuário enviar um prompt.
SessionStart

Ao iniciar uma nova sessão do Claude Code.

 
# Exemplo: rodar testes após cada edição
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "npm test --passWithNoTests"
          }
        ]
      }
    ],
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "notify-send 'Claude terminou!'"
          }
        ]
      }
    ]
  }
}

Configuração

Arquivos de configuração em ordem de precedência (do mais específico ao mais geral):

Arquivo Escopo
.claude/settings.json

Configurações do projeto — versionadas, compartilhadas com o time.
.claude/settings.local.json

Overrides locais do projeto — não versionadas (adicione ao .gitignore).
~/.claude/settings.json

Configurações globais do usuário — aplicadas em todos os projetos.

 
// ~/.claude/settings.json — exemplo completo
{
  "model": "claude-sonnet-5",
  "theme": "dark",
  "permissionMode": "default",
  "allowedTools": [
    "Read",
    "Edit",
    "Write",
    "Bash(git *)",
    "Bash(npm test*)"
  ],
  "env": {
    "ANTHROPIC_API_KEY": "sk-ant-..."
  },
  "mcpServers": { /* veja seção MCP */ },
  "hooks": { /* veja seção Hooks */ }
}

Dicas Avançadas

📋

Contexto via stdin

Passe arquivos via pipe: cat file.py | claude -p "Explique"

🔁

Loop de Acompanhamento

Use /loop 5m /review para revisões periódicas automáticas de código.

📸

Imagens no Prompt

Arraste imagens ou use @caminho/imagem.png para incluir screenshots no contexto.

🗂️

Referência a Arquivos

Use @src/app.ts no prompt para referenciar arquivos sem copiá-los.

🤝

Multi-agente

O Claude pode spawnar subagentes para paralelizar tarefas complexas e independentes.

🔒

Padrões de Permissão

Use Bash(git *) para permitir todos os comandos git mas nenhum outro Bash.

💾

Sessões Persistentes

Use --continue ou --resume <id> para retomar conversas anteriores.

🏗️

Modo Plan

Peça ao Claude para entrar em Plan Mode antes de implementar para revisar a abordagem primeiro. 

# Receitas úteis no terminal

# Analisar output de um comando
npm test 2>&1 | claude -p "O que está falhando e como corrigir?"

# Gerar commit message a partir do diff
git diff --staged | claude -p "Escreva uma mensagem de commit"

# Code review do PR antes de fazer push
git diff main | claude -p "Faça code review focando em bugs e segurança"

# Instalar Claude Code globalmente
npm install -g @anthropic-ai/claude-code

# Verificar versão
claude --version
